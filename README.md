# 🏆 GitHub Achievement Lab

Repositório-laboratório para aprender GitHub na prática e acompanhar conquistas de perfil de forma transparente.

## Objetivos

- praticar issues, branches, pull requests e merges;
- documentar os requisitos conhecidos das conquistas do GitHub;
- registrar progresso sem falsificar estrelas, revisões ou colaboração;
- manter exemplos simples e úteis para estudo.

## Conquistas-alvo

- Quickdraw
- Pull Shark
- YOLO
- Pair Extraordinaire (requer colaboração real)
- Starstruck (requer estrelas reais)
- Galaxy Brain (requer respostas aceitas)
- Public Sponsor (requer GitHub Sponsors)

> Este projeto não é afiliado ao GitHub. Os critérios de achievements podem mudar.
