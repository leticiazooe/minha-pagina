# Guia de conquistas do GitHub

Este arquivo registra os critérios conhecidos para achievements do perfil.

## Quickdraw
Fechar uma issue ou pull request poucos minutos após abrir.

## Pull Shark
Ter pull requests criados pela conta e posteriormente mergeados.

## YOLO
Mergear um pull request sem revisão de código.

## Pair Extraordinaire
Participar como coautora real em commit(s) de um pull request mergeado.

## Starstruck
Ter um repositório público que alcance o número exigido de estrelas reais.

## Galaxy Brain
Ter respostas aceitas em Discussions elegíveis.

## Public Sponsor
Patrocinar trabalho open source por meio do GitHub Sponsors.

## Princípios deste laboratório

- não usar contas alternativas para fabricar estrelas, reviews ou respostas;
- usar branches e PRs para mudanças reais neste repositório;
- manter histórico transparente do que foi feito;
- revisar os critérios periodicamente, pois o GitHub pode alterá-los.
